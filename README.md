# XII PPLG 2 — Website Angkatan

Website resmi kelas **XII PPLG 2**, SMK Negeri 1 Beringin — angkatan 2024.

## Tentang

Website ini bukan sekadar profil kelas. Ini arsip kenangan tiga tahun: dari
hari pertama masuk sekolah, praktik di laboratorium, hingga wisuda.

## Halaman

| Route | Deskripsi |
|---|---|
| `/` | Beranda dengan slideshow, intro, highlight, dan galeri kenangan |
| `/sambutan` | Surat dari kepala jurusan |
| `/pengajar` | Daftar pengajar dengan kesan dari kami |
| `/profil` | Timeline sejarah jurusan |
| `/struktur` | Susunan pengurus dan anggota |
| `/momen` | Timeline momen kelas |
| `/tentang` | Penjelasan jurusan dan prospek kerja |
| `/angkatan` | Halaman personal untuk angkatan 2024 |

## Teknologi

- **React 18** + **Vite** — build tool cepat
- **Tailwind CSS v4** — styling dengan tema kustom
- **Motion (Framer Motion)** — animasi halus
- **React Router v7** — navigasi SPA
- **React Helmet Async** — meta tag per halaman
- **Lucide Icons** — ikon SVG konsisten
- **Vercel Analytics** — statistik kunjungan
